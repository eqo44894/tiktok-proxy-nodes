## 为什么澳洲节点的报价从 67 元到 374 元都有

这是准备下单时最容易踩的坑。同一个澳洲产品，中文网络上至少流传着三个互相打架的数字。

一份 GitHub 测评写澳洲套餐"优惠后约 78.7 澳元/月"，按 4.7 左右汇率折算接近 374 元人民币。主机测评站 zjcp.cc 在 2026 年 8 月的表格里写澳大利亚 2 核 1GB / 2TB / 200Mbps 是 67.76 元/月。digvps 记录的澳洲墨尔本 AU_2230 则是 93.21 元/月、年付 1119 元。三者配置不完全一致，但差出五倍以上，已经没法用配置差异解释。

再往官网看，WePC 产品页上澳洲 TikTok 专用套餐的起价标的是 AUD$14.90/月。这是最低配的起价，不是表格里那些中配型号的价格。四个数字摆在一起，任何"参考价"都失去意义。

价格对不上的原因不难猜：澳元计价的套餐被不同人按不同汇率折算过，有的写的是原价，有的写的是用码后的价，有的表格干脆是从更早的页面抄下来的。连 zjcp.cc 自己都在同一篇文章里既说"价格表中的费用为原价"，又说"折后日本 TikTok 专线 VPS 最低 81 元/月起"，两个口径自己打架。

## 原生 IP 和双 ISP 家宽，标了"家宽"不等于干净

WePC 的套餐分两类 IP。原生 IP 是数据中心分配的当地原生 IPv4，归属地在该地区，价格低一些，适合普通起号、发视频、轻量直播。双 ISP 家宽 IP 更接近真实家庭宽带，理论上风控等级更低，适合高权重账号、直播推流和需要绑定支付的场景，价格贵一档。

问题在于"标了双 ISP 家宽"和"实际被数据库认成家宽"是两件事。digvps 的实测记录里反例不少：

英国双 ISP 家宽_TK专用，2025 年 7 月的点评原话是"类目中『双 ISP 家宽』和实际属性差异较大……一脉传承的低性能"，评级只有 E4。菲律宾 TikTok 专线在 2024 年 1 月被记录为"IP 的家宽属性已经全掉了"，这个型号后来下架了。美国纽约双 ISP_38 家宽，2025 年 6 月的评价是"IP 确实很多家宽属性，只是这个风险程度……"，评级 E5-。韩国 SEJONG 双 ISP 家宽 2026 年 8 月的记录是"IP 不错，只是两个友商同款产品都送中了，不清楚它能坚持多久"，送中指 IP 被 Google 判定成中国大陆归属。

买之前值得花十分钟做的事：拿到 IP 后自己跑一遍主流 IP 质量数据库，看它被标成 Residential、ISP 还是 Hosting，风险分多少。商家页面写的是宣传口径，数据库认的是另一套。

## 各节点现状：这几个最近明显变差

前排文章普遍只列配置和价格，不说节点这半年发生了什么。下面按时间倒序，都是有明确日期的实测记录。

**越南，2026-10-17**：上游变更，目前 IP 质量一般，部分数据库中的风险标记较多。对照 2024 年 11 月的记录"越南原生 IP，风险度低，媒体基本全解"，两年间变化很大。现在买越南要自己验 IP。

**新加坡，2026-10-15**：上游有所变动，仍是新加坡原生 IP，但部分数据库已将其标记为风险 IP。新加坡家宽版另有一条 2025-06 的记录：国内直接访问非常糟糕，从香港访问速率一般，只有从新加坡本地访问能跑到 180Mbps。做新加坡市场，机器基本得当本地中转节点用。

**泰国，2026-10-07**：整体稳定性还不错，但带宽冗余不足，不少时段的实测速率仅为个位数。标称 50Mbps 的套餐跑出个位数，直播基本没戏。

**韩国家宽_TK直播，2026-07-09**：速率下降了很多，目前已不适合作为直连线路使用。官网对韩国双 ISP 的说明也写着"电信移动直连，联通绕路，直播建议中转"，和"直连好用"的印象对不上。

**日本，2026-07-12**：产品上游已经完全变更，硬件和 IP 都换过，目前 IP 质量不错。但 2024 年 12 月的记录里"实测下来电信不行，联通回程看到个软银"，电信用户体验要打折。

**美国_VPS，2026-06-06**：线路没什么变化，但"去年那波攻击之后 IP 不美了"。2024 年 6 月这个产品还是"多个数据库标记为家宽，IP 全解，风险度低"。美国洛杉矶 9929_38 家宽另有一条 2025-09 的记录："机器超售有些厉害。"

反过来，几个节点近期状态是往好的方向或至少没退：**澳洲墨尔本** 2026-03-31"时隔两年，IP 质量依然惊艳"；**德国** 2026-04-01"IP 质量依然优秀"；**台湾** 2026-03-22"全面更新，IP 依然优秀"；**巴西** 2026-03-23"虽然并非家宽，但巴西原生 IP 搭配不错的质量，就目前而言别无他选"；**新西兰** 2026-10-01 硬件一般但 IP 表现不错。

## 退款、限速，以及写在条款里的那些事

退款政策有两个流传版本，差别不小。

一份 2026 年 3 月的记录写得比较细：3 天内且流量使用不超过 10GB，可以全额退款到账户余额，或者扣每笔 10 元手续费后原路退回；超过 3 天或流量超过 10GB，不支持原路退款，可按比例退到账户余额，余额不可提现。另一份更早的资料写的是"流量使用不超过 5%"，条件更严。

两个版本无法确认哪个是当前官方条款，下单前在结算页或服务条款页自己看一眼，以那上面的为准。能确定的是退款窗口很短，三天内测完 IP 和回程，别拖。

超流量这块，部分套餐超量后限速到 5Mbps。官网产品页上马来西亚、英国等几个型号明确写着"超流量限速 5M"，买之前对一下自己的月流量需求。5Mbps 拿来发视频勉强，直播直接不用想。

服务条款里还有几条影响使用的：

- **禁止使用 Shadowsocks 协议**，官网产品页和条款都写了，建议换其他主流协议。
- **禁止 BT、迅雷、uTorrent 等下载工具**，也禁止公开代理、CDN 服务、流量挖矿、PT、流量交换、爬虫、集群计算这类持续占资源的用法。
- **禁止嵌套虚拟化**（独立服务器除外），想在上面再开一层虚拟机的方案行不通。
- **未经授权禁止转售**。
- HK_3CMI 系列明确不退款。
- 迁移要收每次 2.5 澳元的迁移费，且月付产品剩余时长需大于 15 天才能转。

这几条不是摆设，违反后商家有权直接终止服务且不退款。拿它当跳板机、下载机或者建 CDN 节点的，别买。

## 哪些人买了会后悔

**跑重负载的。** 大部分 TikTok 套餐是 1 核 512M 或 2 核 512M 起步，硬盘 IO 被 digvps 在多个节点吐槽过。第三方实测的一台机器是 Xeon Gold 6138 单核 2.00GHz，512M 套餐实际可用内存 487MB，SSD 平均读写 163MB/s。跑 WordPress 小站、轻量数据库可以，视频转码、大型数据库、爬虫集群不用考虑。

**要企业级 SLA 的。** 客服在线时间是北京时间 9:00–21:00，其余时间走工单。热门机房（香港、日本）偶尔断货。这是小团队的响应节奏，不是 7×24 工程师值守。

**电信单线且对延迟敏感的。** 官方自己的线路说明里，德国"电信需中转"，新加坡"电信必须中转"，泰国"电信除上海其余必须中转"，西班牙"电移连直连访问都困难"，印尼"电信联通及部分移动需要中转"。电信用户体验普遍弱于联通和移动。真要直连，先看该节点的官方线路说明，别只看评级。

**想拿它当通用 VPS 的。** 这套产品的定价里，IP 质量占了大头，CPU 和 IO 是附送的。同样的钱在通用云厂商能买到配置高得多的机器，只是 IP 是机房段。
